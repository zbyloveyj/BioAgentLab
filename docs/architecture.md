# Architecture

```text
Research question
      |
Generation -> Reflection -> Evidence retrieval/verification
      |              |                  |
Proximity dedupe   Failure log      Claim-evidence graph
      \              |                  /
       Ranking <-> Scientific debate
              |
          Evolution
              |
          Meta-review
              |
     Scientific Supervisor
              |
   Human approval / experiment
```

核心原则是：生成与核验分离，关联与机制分离，评分与证据分离，自动化结论与人工决策分离。
