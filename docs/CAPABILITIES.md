# 能力、测试与未验证边界

## 已实现且有自动测试

- Evidence/Candidate数据契约、来源标识去重、研究级聚合、情境过滤、冲突保留、默认排除合成材料。
- 候选修订版本化与旧核验链接失效。
- 工具白名单、参数签名、验证器、显式审批和动作预算。
- 工作区路径检查、单进程事件日志、DAG拓扑检查。
- 本地BM25、英文词项与中文双字片段、空输入与重复标识检查。
- JSON契约的生成、反思、修订；成对倡议/评审接口，顺序互换检查和引用存在性检查。
- Elo与无法比较状态；CLR、BH、样本审计、标识对齐、供体/细胞类型聚合。
- 离线MicroMetaCell报告、日志、清单与预算耗尽时的部分报告。

## 可选接口：实现不等于在线已验证

`pubmed.py`实现只读E-utilities请求与XML/JSON解析；测试覆盖本地响应样例与输入边界。真实网络、服务限额和当前远端响应需要使用者在授权环境中核验。

`providers.py`实现文本型Responses API适配；模型名称由使用者提供。没有自动调用真实模型或消耗用户额度，测试不声称验证供应商当前在线能力。

`debate.py`可以接入满足LLMClient接口的模型；当前自动测试使用脚本替身。综合演示为了离线与确定性，仍使用显式启发式judge。

## 不能据此声称的能力

证据台账不自动读取并验证全部原始文献，引用存在不等于支持正确。工具注册不是完整安全沙箱。供体聚合不是正式差异表达。CLR/BH不是完整微生物统计流程。没有真实数据效果、临床效度、自动实验能力或外部复现性能结论。

教材的知识图谱、MCP、行动发现、领域工作流与因果章节包含设计教学；不是每一个理论模块都已经提供生产适配器。升级以代码、测试和实际运行记录为准。
