# AI Agent for Biology — Book

中文配套教材：

**《AI Agent for Biology：从 LLM、Tool Use、RAG 到自主生物医学科研智能体》**

目标不是教会读者多写几个 Prompt，而是建立完整的科研智能体知识体系，并最终亲手实现一个可运行的 BioDiscovery Agent。

## Part I — Foundations
1. 从 LLM 到 AI Agent
2. Prompt、Context 与 In-context Learning
3. Memory：智能体为什么需要记忆
4. Agent Loop：感知、思考、行动与反馈

## Part II — Planning and Tool Use
5. Tool Calling：让模型调用真实世界工具
6. ReAct：Reasoning + Acting
7. Plan-and-Execute 与任务分解
8. Workflow、Orchestration 与状态管理

## Part III — Knowledge and Evidence
9. RAG：从参数知识到外部知识
10. Agentic RAG：会主动追问证据的检索系统
11. Knowledge Graph 与生物医学知识网络
12. Evidence Grounding、Provenance 与证据等级

## Part IV — Scientific Multi-Agent Systems
13. Generation Agent：提出科学假设
14. Reflection Agent：像审稿人一样挑错
15. Scientific Debate：让假设正面对抗
16. Ranking Agent：从打分到 Elo 科学锦标赛
17. Evolution + Proximity：进化与去冗余
18. Meta-review + Supervisor：总结失败模式并动态调度

## Part V — AI Agents for Biology
19. Literature Agent
20. Genomics Agent
21. Single-cell Agent
22. Microbiome Agent
23. Multi-omics Agent

## Part VI — Reliability
24. Benchmark、Evaluation、Reproducibility 与安全边界

## Part VII — Capstone
25. BioDiscovery Agent：从科学问题到可验证研究方案

## 学习方法

每章遵循同一结构：

概念 → 类比 → 数学/算法 → Agent 架构 → Biology 案例 → Python 实现 → 常见错误 → 练习 → 小项目

最终不是读完一本书，而是边学边把 BioAgentLab 自己构建出来。
