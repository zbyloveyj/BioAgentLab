# 《BioAgentLab：面向生物学发现的证据型 AI Agent》

本目录保存教材的可版本控制源稿。执行 `python scripts/build_book.py` 会生成完整 Markdown 书稿和 A5 PDF。

## 七篇结构

1. 基础：从语言模型到科学 Agent
2. 架构：生成、反思、排序与进化
3. 证据：RAG、工具、记忆与核验
4. 科学方法：假设、反证、统计与复现
5. 生物学工作流：微生物组、单细胞与多组学
6. 多智能体发现：辩论、总控与行动发现
7. 综合实战：精神疾病相关微生物 HGT 重塑

> 书中所有结果分为真实资料、教学模拟和待验证假设三类；不得把示例数字当成真实研究结论。
