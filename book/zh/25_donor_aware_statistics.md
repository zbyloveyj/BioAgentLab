# 第25章 供体层级统计：不要让细胞数量制造精确幻觉

## 25.1 独立重复是设计问题

同一供体的细胞共享遗传背景、环境、处理和采样条件，因此不能简单当成大量独立供体。一个研究有十位供体、十万个细胞，生物学重复并不会变成十万个。单细胞差异表达研究已经展示忽略重复结构可能产生严重的假发现。[R13]

这不意味着细胞层面信息没有价值，而是统计模型必须尊重层级。可以使用供体内聚合，也可以使用适当的层级模型；具体选择取决于问题、数据和方法假设。

Agent最重要的入口问题是：“我们要推断的独立单位是什么？”这个问题应在选择检验之前回答。

## 25.2 Pseudobulk的基本思想

对同一供体、同一细胞类型的原始计数求和，得到供体×基因矩阵。随后使用与计数数据和实验设计匹配的方法比较条件。聚合不是随便把细胞分成若干组，而是按真实生物重复分组。

如果随机把所有细胞分成十个伪组，就破坏了供体结构。看起来仍有十列数据，但它们不是十个独立供体。技术上的矩阵形状不能替代研究设计。[R13]

```python
from collections import defaultdict


def pseudobulk(rows):
    totals = defaultdict(lambda: None)
    for row in rows:
        key = (row["donor_id"], row["cell_type"])
        counts = row["counts"]
        if totals[key] is None:
            totals[key] = [0] * len(counts)
        if len(counts) != len(totals[key]):
            raise ValueError("Gene dimension mismatch")
        if any(type(v) is not int or v < 0 for v in counts):
            raise ValueError("Expected nonnegative integer counts")
        totals[key] = [a+b for a, b in zip(totals[key], counts)]
    return dict(totals)
```

教学实现展示聚合逻辑；完整项目还会检查空标识、重复细胞、基因维度和输入有限性。真实大矩阵应使用适当稀疏实现，避免不必要的内存复制。

## 25.3 聚合之后还需要什么

Pseudobulk不是按下按钮就完成差异分析。仍需检查每个供体每种细胞类型的覆盖、基因过滤、文库规模、设计矩阵和重复测量。某细胞类型只在一个条件下被充分捕获时，解释尤其需要谨慎。

计数归一化、离散度估计和模型拟合应交给成熟统计工具，并记录实际版本与参数。本书的标准库示例不实现正式负二项差异表达，也不把简单均值差当成生产级替代。

对配对或纵向数据，设计矩阵应表达供体与时间关系。不能把多个时间点当成不同人，再声称样本量增加。

## 25.4 效应大小与不确定性

P值回答的是指定模型与零假设下的统计问题，不直接表示效应大小、机制重要性或可重复概率。报告应同时给出方向、效应估计和不确定范围。

一个极小但稳定的变化可能具有统计显著性，却未必具有实际重要性；一个大效应但样本少的结果可能不显著，却值得进一步研究。Agent不应只按P值给基因或机制排优先级。

在跨组学解释中，还需要区分细胞比例变化与细胞类型内部状态变化。不同问题对应不同统计对象，不能混合为一个“免疫激活分数”而不说明构造方式。

## 25.5 多重检验与BH校正

当同时检验许多基因或关系时，应明确检验族与错误控制目标。BH方法将排序后的P值按检验数量调整，并进行反向累积最小值处理以保持单调性。[R16]

```python
import math


def bh_adjust(pvalues):
    p = list(pvalues)
    if any(not math.isfinite(x) or not 0 <= x <= 1 for x in p):
        raise ValueError("Invalid p-value")
    order = sorted(range(len(p)), key=p.__getitem__)
    q = [0.0] * len(p)
    running = 1.0
    for rank in range(len(p), 0, -1):
        idx = order[rank-1]
        running = min(running, p[idx] * len(p) / rank)
        q[idx] = running
    return q
```

校正不能补救伪重复、错误零假设或数据泄漏。也不能把未显著结果解释成证明没有效应。依赖结构与具体错误控制条件需要结合分析背景评估。

## 25.6 基因集与通路解释

通路富集需要明确背景集合、基因标识、方向和方法。对差异基因列表，背景通常应反映实际可检测或纳入检验的基因，而不是无条件使用整个基因组。不同数据库存在重叠，多个显著通路可能来自同一小组基因。

Agent可以把富集结果压缩成主题，但必须保留原始条目和驱动基因。不能仅凭一个通路名称把细胞状态命名为某种确定功能，更不能把表达富集当成实际通量或活性测量。

对关键机制，应回到基因层面检查方向与供体分布，并寻找独立功能证据。主题总结是解释步骤，不是新的实验结果。

## 25.7 故障注入式验证

可以构造合成数据，让不同供体具有不同基线，但条件没有真实效应。比较错误的细胞独立分析与供体层级汇总，观察伪重复如何制造不合理精确性。这个练习用于理解设计，不用于声称某种方法在所有真实数据上最优。

还应测试聚合是否守恒：每个基因在全部细胞中的计数总和，应等于所有聚合组的计数总和。若不一致，先修复程序，而不是解释为生物差异。

## 25.8 练习与参考思路

**练习一：**某供体有5000细胞，另一供体只有500细胞，能否把前者视为十个重复？参考思路：不能，细胞数影响测量精度与覆盖，但不增加独立供体数量。

**练习二：**聚合后某细胞类型只有两位供体，应该怎样报告？参考思路：明确样本限制，避免强推断；增加细胞不等于解决供体数不足。

**本章要点：**独立单位来自研究设计；聚合、模型拟合、多重检验和功能解释是不同检查层。
