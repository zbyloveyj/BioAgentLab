# 第22章 微生物生态：组成、稳定性与网络解释

## 22.1 相对丰度不是绝对数量

设样本中有三类群，绝对数量分别为10、10、10，相对丰度均为三分之一。若第一类群增加到20，其他两类保持10，它们的相对丰度仍会下降。由此可见，相对减少不必然表示绝对数量减少。

这个简单例子说明组成约束为什么影响微生物组分析。对数比方法关注分量之间的相对关系；PhILR等研究把这种思想与系统发育结构结合。[R15] 本书不把某一种变换当作所有任务的唯一答案，而是要求解释与数据尺度匹配。

Agent看到“许多菌下降”时，应先检查输入是相对丰度、绝对定量还是其他标准化信号。不同尺度需要不同表述。

## 22.2 CLR的定义与零值问题

对严格正的D维向量，中心化对数比变换为：

$$\operatorname{clr}(x_i)=\log x_i-\frac{1}{D}\sum_{j=1}^{D}\log x_j.$$

其分量和为零。将整个向量乘以同一正数，不改变CLR结果，这是它表达相对关系的一个性质。零值不能直接取对数，因此零值处理是分析选择，不是可以隐去的技术细节。

```python
import math


def clr(values, pseudocount=None):
    x = [float(v) for v in values]
    if not x or any(not math.isfinite(v) or v < 0 for v in x):
        raise ValueError("Expected finite nonnegative values")
    if sum(x) == 0:
        raise ValueError("All-zero sample")
    if pseudocount is not None:
        if not math.isfinite(pseudocount) or pseudocount <= 0:
            raise ValueError("Invalid pseudocount")
        x = [v + pseudocount for v in x]
    if any(v <= 0 for v in x):
        raise ValueError("Explicit zero handling required")
    logs = [math.log(v) for v in x]
    center = sum(logs) / len(logs)
    return [v - center for v in logs]
```

固定伪计数的作用依赖输入单位，加入后也会改变原有尺度不变性质。应记录单位、选择理由和敏感性分析，不能自动加一个数后不再说明。

## 22.3 稳定生态骨架与核心类群

“核心”需要操作性定义，可以涉及检出率、丰度、跨研究复现和变化程度。不同定义回答不同问题：高检出不一定高丰度，低变异不一定具有关键生态作用，跨人群稳定也不意味着每个人都存在同一组菌。

对教学项目，可以先在健康参考数据中计算明确指标，再评估跨研究稳定性。重点应放在跨人群可重复的生态结构，而不是把地理差异当作唯一叙事。地理、饮食和技术批次可以作为解释与敏感性因素。

Agent可以组织指标计算和阈值比较，但不应根据最有利的疾病区分结果反向选择核心定义，然后把同一数据上的性能称为独立验证。参考集合与验证集合需要分开。

## 22.4 网络边不等于生态相互作用

从丰度数据估计的网络边，可能来自直接相互作用、共同环境、宿主因素、组成约束或批次。即使使用条件关联方法，也不能自动获得因果生态网络。

网络模块可以帮助总结共变结构，但模块命名应依据实际成员和功能证据，不应仅由模型赋予一个吸引人的机制标签。对网络稳定性，可以重采样、留一研究、改变预处理或阈值，观察边与模块是否稳定。

自研算法可以具有价值，但需要明确优化目标、假设和评估。创新不一定意味着与所有现有算法进行机械比较；至少需要合理基线、消融和能够检验预期优势的任务。

## 22.5 差异分析与协变量

差异模型应与数据类型和研究设计匹配。协变量选择需要依据研究问题与因果结构，不能为了使P值更小反复增删。年龄、性别、药物和批次的处理，应在方法记录中明确。

对于多个研究整合，研究效应可能与疾病组成相关。简单批次协调若删除了真实生物差异，或保留了混杂结构，都可能误导后续分析。应通过研究内效应、留一研究验证和敏感性分析评估，而不是只看PCA图是否混在一起。

Agent的角色是提醒这些检查并组织结果，不是仅凭一张降维图宣布批次效应已经消失。

## 22.6 纵向变化与独立单位

同一个人的多次样本不独立。研究稳定性时，应明确比较相邻时间点还是所有时间对，并避免采样次数较多的人在总体结果中获得过大权重。可以先在受试者内汇总，再进行群体层面比较，或使用适当的重复测量模型。

余弦相似度、距离和相关性度量各有尺度假设。使用前要说明输入是原始丰度、变换后数据还是模型表征。较高相似度不等于所有关键功能稳定，也不直接说明生态恢复能力。

时间间隔同样重要。一天与一年间的相似度不能无条件混合。Agent应保存时间信息，并让统计工具按预定策略处理。

## 22.7 生态解释的证据层次

一个类群与疾病有关，可以提出候选功能问题；若进一步发现相关基因或通路，可以缩小机制范围；若有代谢测量和宿主响应，才逐步形成跨尺度证据。每一步都增加信息，但不会自动消除混杂。

报告应把类群、功能、代谢和宿主层面分别展示，再解释它们之间的一致与不一致。不要为了讲一条完整故事而隐藏某一层没有结果的事实。

## 22.8 练习与参考思路

**练习一：**CLR分量和不接近零，先检查什么？参考思路：检查实现、数值输入和矩阵轴；这是可以由单元测试发现的程序问题，不需要模型解释。

**练习二：**网络中的中心节点是否就是最佳干预靶点？参考思路：不一定。中心性依赖估计方法与数据，也不等于因果作用、可干预性或安全性。

**本章要点：**微生物生态解释必须尊重组成约束、研究结构和独立单位；网络与核心定义都需要验证。
