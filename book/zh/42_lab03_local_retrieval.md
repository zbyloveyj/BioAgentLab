# 实训三 建立一个可以检查的本地检索器

## 目标与语料

本实训使用四条自己编写的教学文档，不下载受版权限制的全文。文档包括微生物代谢、宿主细胞、研究设计和无关主题。目标是理解查询、分词、排序与证据含义之间的区别。

```python
from bioagent.retrieval import Document, BM25Index

corpus = [
    Document("D1", "微生物代谢与代谢物测量需要区分功能和通量。", "synthetic://D1"),
    Document("D2", "宿主细胞受体表达不等于配体信号已经激活。", "synthetic://D2"),
    Document("D3", "供体标识与样本配对决定跨组学统计的独立单位。", "synthetic://D3"),
    Document("D4", "图像分辨率与字体排版属于文档制作问题。", "synthetic://D4"),
]
index = BM25Index(corpus)
for hit in index.search("微生物代谢", top_k=3):
    print(hit.document.identifier, round(hit.score, 3))
```

预期D1排在最前。具体分数由当前实现和语料决定，不具有科学证据强度的含义。修改语料数量或文档长度，分数也可能变化。

## 检索词的影响

依次查询“宿主细胞”“受体表达”“供体配对”和一个不存在的词。观察返回文档是否符合预期。空结果是合法检索结果，不应自动转成一段猜测性回答。

现在把“受体表达”改成一个措辞不同的同义表达。轻量词项检索可能漏掉材料，这展示了词面匹配的限制。你可以增加明确的同义词扩展，但应保存扩展词，避免查询含义悄悄变化。

```python
queries = ["宿主细胞", "受体表达", "供体配对", "不存在的罕见词组"]
for query in queries:
    print(query, [h.document.identifier for h in index.search(query)])
```

## 精确标识与语义查询

给某条文档加入稳定标识，例如 `metabolite_demo_001`，再查询该标识。精确匹配在实体任务中很重要，不能仅依赖语义近邻。一个名字相似的代谢物可能具有不同结构或功能。

真实系统可以结合词项检索与向量检索，但必须评估各自贡献。不要把替换成向量数据库视为质量必然提高；检索是否更好应由任务上的召回与相关性判断。

## 建立一个小型标注集

为四个查询指定预期相关文档，然后计算前k条结果是否覆盖它们。不要在看到结果后不断修改“标准答案”，否则评价失去意义。

```python
gold = {
    "微生物代谢": {"D1"},
    "宿主细胞": {"D2"},
    "供体标识": {"D3"},
}
for query, relevant in gold.items():
    found = {h.document.identifier for h in index.search(query, top_k=2)}
    recall = len(found & relevant) / len(relevant)
    precision = len(found & relevant) / len(found) if found else 0.0
    print(query, precision, recall)
```

这只是三条教学问题，不足以评价真实生物医学检索能力。它的价值在于让指标有明确分母，并使错误可以定位。

## 加入冲突文档

添加一条主题相似但结论相反的文档，再检索同一问题。检索器应该能够返回它，因为检索相关性不要求材料支持初始假设。若系统只寻找支持性措辞，就会产生确认偏差。

随后把结果交给证据台账，分别标记方向。不要把BM25分数直接转换成支持权重。一条高度相关的反对证据，可能比一条低相关支持材料更重要。

## 重复文档与研究独立性

复制D1为另一个文档标识，观察它是否占据多个结果位置。检索器允许不同文档，但后续应识别它们是否属于同一研究。文档层去重与研究层去重有不同作用。

对长论文切分成多个chunk时，同样需要保留父文档与研究标识。否则一个长文献可能因片段多而在上下文中获得不成比例的影响。

## 提交与参考答案

提交语料、查询标注、指标和一个检索失败案例。解释失败来自词语、切分、语料覆盖还是结果排序，并提出一个可以测试的改进。

参考答案不应说“检索分数高，所以结论可靠”。应指出检索只选择待阅读材料，证据方向、研究设计和适用范围在下一层核验。
