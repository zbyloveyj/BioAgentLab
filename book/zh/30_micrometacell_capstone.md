# 第30章 综合项目：MicroMetaCell教学工作流

## 30.1 项目要回答什么

综合项目围绕一个受约束问题：给定微生物、代谢物与宿主细胞的教学材料，系统能否正确整理数据、识别证据缺口、比较候选解释，并输出不超出依据的报告？它不是自动发现真实疾病机制的演示。

所有示例实体、数值与证据片段均标记为合成。项目的成功标准是程序行为正确：识别重复来源，不把模拟证据当成真实研究，遇到缺失关系时停止强结论，并生成可追溯产物。

这种小型完整闭环比只有目录的庞大框架更适合学习。你可以逐步替换其中一个模块，观察它如何影响整个系统。

## 30.2 数据与证据分别进入

数值数据包括示例样本、微生物向量和单细胞计数。证据数据包含文档标识、研究标识、claim、方向与来源状态。前者用于检查计算，后者用于检查论证，两者不能混成一段提示词。

系统先审计标识与数值，再运行CLR或pseudobulk等教学计算。随后检索本地证据材料，建立台账，检查候选假设的每条关系。计算结果不自动成为文献证据，文献证据也不替代当前数据质量。

```text
Synthetic inputs
    -> audit
    -> registered numerical tools
    -> local retrieval
    -> evidence ledger
    -> hypothesis critique
    -> pairwise preference ranking
    -> revision and re-verification
    -> report + manifest + trace
```

图中的每一步都有输入输出，不是让一个模型一次性编写所有结果。

## 30.3 运行方式

在仓库根目录完成可编辑安装后，运行离线演示。默认不访问网络、不需要API key，也不会读取读者的真实数据。

```bash
python -m pip install -e ".[dev]"
python -m pytest
python -m bioagent demo --out runs/micrometacell
```

输出目录包含结构化报告、可读报告、事件日志和清单。清单记录软件版本与关键文件摘要。相同目录已存在时，程序默认拒绝覆盖，避免不知不觉替换旧结果。

读者应首先查看报告中的模式字段。只有明确的合成标记保留到最终产物，才能避免把教学演示误当作真实研究结果。

## 30.4 检查证据链的关键空缺

示例包含A到M、M到C等不同claim，有支持片段、冲突片段和重复研究记录。台账按研究标识去重，并把合成材料单独处理。默认真实证据判断不接受合成条目。

教学模式可以展示“若这些条目是合格输入，台账将如何组织”，但最终报告仍必须写明没有真实生物学验证。演示中的相对排名仅用于观察算法行为。

修订候选后，旧核验关系被清空或重新检查。这个步骤专门防止“把已获支持的句子换成更强主张，却保留原支持状态”的错误。

## 30.5 怎样阅读事件日志

事件日志按顺序记录任务开始、工具调用、检索、核验、比较、修订和报告。每条事件包含动作与状态，便于定位失败。它不是模型内部思考全文，而是可检查的操作记录。

如果预算不足，日志应显示在哪一步停止，并保留已经完成的结果。如果输入有重复标识，应在计算前失败，而不是继续生成报告。读者可以故意制造这些情况，确认系统是否按预期拒绝。

日志与报告可能包含不同详细程度，但关键状态必须一致。报告不能声称全部完成，而日志显示某个前置任务失败。

## 30.6 替换一个模块，而不是一次替换全部

第一步可以换成本地真实但合规的文献元数据，仍保持数值合成；第二步换成已经审计的小型真实数值表；第三步再接入外部模型或专业分析工具。每次只改变一层，更容易理解错误来源。

接入真实材料时，不要仅把 `synthetic` 改成false。必须补齐来源、研究标识、适用情境和核验过程。布尔字段不能把模拟材料变成真实证据。

同样，把离线模型替换成远程模型，只增加语言能力，不会自动提高数据质量或统计有效性。工具和证据的验收规则仍然保留。

## 30.7 从教学项目到研究系统还缺什么

真实研究需要领域工具适配、合法数据接入、充分评估、用户权限、持久化任务管理与更强的异常恢复。对于单细胞和宏基因组，还需实际专业软件与数据库环境。

本版已经实现的内容应以测试和代码为准；计划中的高级能力不应列为完成。一个透明的能力边界，远比一个把所有生物学软件名字都列上去的README更有用。

项目也没有自动执行湿实验或临床决策功能。机制验证建议只是需要专家审查的研究对象。

## 30.8 练习与参考思路

**练习一：**运行后报告中出现真实机制已证实，应如何定位？参考思路：检查报告模板、证据合成标记与资格闸门；这应被回归测试捕获。

**练习二：**替换检索器后结果更好，如何证明改进来自检索？参考思路：保持模型、证据库和任务不变，比较检索指标与下游引用支持，并记录成本。

**本章要点：**综合项目交付一个可检查闭环；教学完成不等于真实科学验证完成。
