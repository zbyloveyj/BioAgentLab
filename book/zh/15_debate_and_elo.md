# 第15章 Scientific Debate：比较假设与 Elo 排名

## 15.1 为什么成对比较有用

直接要求模型给十个假设打分，可能出现量尺漂移：前几个评分严格，后几个逐渐宽松。成对比较把问题缩小为“在相同标准下，A 与 B 哪一个更值得优先验证”。AI co-scientist 研究使用了多智能体评审与锦标赛式比较的设计，为这种思路提供了实例。[R05]

但成对比较仍然依赖评审标准。如果评审偏爱熟悉的机制，排名可能奖励常识化；如果偏爱复杂叙事，排名可能奖励无依据的连接。比较前必须明确：我们排序的是验证优先级、证据充分性还是潜在影响。这些不是同一件事。

本书的教学排名服务于研究任务的优先级安排，不把名次解释成机制为真的概率。

## 15.2 一场科学辩论应该交换什么

每个候选应提交相同结构的材料：核心陈述、可检验预测、支持证据、冲突证据、关键空缺和所需资源。辩论应该围绕这些对象，而不是围绕表达感染力。

一个合理的回合包括：A 指出自己的最强依据；B 提出针对该依据的替代解释；A 回答是否能区分；评审总结仍未解决的问题。辩论不应允许任何一方临时添加不存在的文献。新出现的事实性陈述必须回到证据检索流程。

为了防止篇幅优势，可以限制两方的输入与输出长度，并随机交换展示顺序。对重要比较，进行位置互换后复评，记录是否改变结论。

## 15.3 分维度记录，不急于合成一个分数

可以分别评价证据适用性、可证伪性、机制差异、验证成本和潜在信息价值。某假设证据较少，但实验能有效区分竞争解释；另一假设证据很多，却难以产生新信息。不同研究目标会给出不同优先级。

把维度保留下来，允许研究者看到权衡。若确实需要加权总分，权重必须公开，并进行敏感性检查。模型自报的“新颖性 9 分”不应未经检索直接进入正式评价。

一个评审结果可以是平局，也可以是无法比较。平局表示在当前标准下相近；无法比较表示材料不足或尺度不一致。后者不应被机械记作双方各得半分，否则缺失材料可能获得不合理奖励。

## 15.4 Elo 更新公式

Elo 最初用于对局表现比较。教学项目借用它更新成对偏好的相对分值，而不宣称其具有科学真值解释。对于候选 A 和 B，预期得分为：

$$E_A=\frac{1}{1+10^{(R_B-R_A)/400}},\qquad E_B=1-E_A.$$

观察到 A 的结果 $S_A$ 后，更新：

$$R'_A=R_A+K(S_A-E_A),\qquad R'_B=R_B+K((1-S_A)-E_B).$$

其中获胜为1，平局为0.5，失败为0。$K$ 控制每次更新幅度；400是借用的尺度参数，不具有生物学意义。两方更新应使用同一对旧分值，不能先改 A 再用新 A 计算 B。

```python
import math


def elo_pair(a, b, outcome, k=24.0):
    if outcome not in (0.0, 0.5, 1.0):
        raise ValueError("Outcome must be loss, draw or win")
    if not all(math.isfinite(x) for x in (a, b, k)) or k <= 0:
        raise ValueError("Invalid rating parameters")
    exponent = max(-300.0, min(300.0, (b - a) / 400.0))
    expected = 1.0 / (1.0 + 10.0 ** exponent)
    delta = k * (outcome - expected)
    return a + delta, b - delta
```

这个实现保持两方总分不变。测试应覆盖平局、强者获胜、弱者获胜、非法输入和极端差值。

## 15.5 排名依赖赛程

如果一个候选只与弱对手比较，另一个候选持续面对强对手，分值的可比性会受影响。对少量假设，可以进行完整成对比较；对大量假设，可以使用分轮采样，但需要保证比较图具有足够连接。

顺序也会影响动态更新。可以固定随机种子、重复不同赛程，并报告名次稳定性。若某两个候选的次序在不同运行中反复交换，报告应保留这种不确定，而不是只展示一次运行的冠军。

更进一步，可以使用成对概率模型或其他排序方法，但更复杂的方法也不能解决评审偏差本身。排序数学与科学评价来源是两个层面。

## 15.6 不要让排名制造虚假的确定性

高 Elo 只表示在指定比较过程中的相对表现。它不能证明候选具有更高真实因果概率，也不能把无证据假设变成已验证机制。若所有候选都存在严重问题，仍然会有第一名；第一名也可能不值得实施。

因此应在排名之前或之后设置资格门槛，例如关键实体无法映射、存在未解决的阻断性方法错误、缺少任何可检验预测时，不进入优先执行列表。排序负责在合格候选中安排资源，门槛负责防止不合格候选因相对排名而获得批准。

教学输出应同时展示证据状态、未解决批评与排名。把三个对象放在一起，读者就不容易只盯住一个数字。

## 15.7 练习与参考思路

**练习一：**两候选初始均1000分，A获胜且K=24，结果是什么？参考思路：双方预期均0.5，因此A为1012，B为988。这个数值差异只反映一次偏好结果。

**练习二：**更换展示顺序后，评审总偏好第一个候选，怎么办？参考思路：记录位置偏差，采用互换复评或盲化展示，检查提示词和评审标准；不能直接把所有结果平均后宣称偏差消失。

**本章要点：**辩论应交换证据与预测；Elo 是相对偏好工具，不是科学真值概率。
