# 第23章 代谢组：跨尺度机制中最容易被跳过的桥

## 23.1 一个峰不一定就是一个已确认代谢物

非靶向代谢组中的特征可能是峰、加合物、同位素或候选化学实体。名称出现在结果表中，并不代表已经通过标准品确认。代谢物鉴定与报告标准强调区分不同确定程度。[R24]

Agent应先读取注释等级、离子模式、质量与保留时间等说明，再决定能否进行实体级机制查询。不能把一个模糊候选名称直接映射到唯一结构，然后生成精确受体机制。

本章不替代质谱数据处理教程，而是说明如何让代谢证据进入科研Agent时不丢失身份与测量不确定性。

## 23.2 身份、数量和来源是三种问题

身份问题是“测到的是什么”；数量问题是“信号代表多少”；来源问题是“由谁产生、在哪里变化”。三者需要不同证据。一个可靠鉴定的代谢物，也可能只有相对信号而没有绝对浓度；一个与微生物相关的代谢物，也可能同时来自宿主或饮食。

因此，代谢记录应包含稳定标识或候选标识、注释依据、单位、样本类型、处理历史以及来源推断的证据。不要把“微生物相关”直接写成“微生物产生”。

```json
{
  "feature_id": "F001",
  "candidate_ids": ["chemical_namespace:example"],
  "identity_status": "putative",
  "measurement": "relative_signal",
  "sample_type": "plasma",
  "source_assignment": "unresolved",
  "batch": "batch_1"
}
```

这个教学记录故意保留不确定，而不是为了数据库整洁只留一个名字。

## 23.3 区室决定解释边界

粪便、血浆、组织和培养体系中的测量不是同一暴露。粪便浓度可能同时受生产、消耗、吸收和排出影响。血浆信号也不自动代表目标组织中的有效浓度。

因此，跨尺度链条应明确区室转换。A与粪便M相关，M在体外作用于C，是两个有用线索；中间仍可能缺少体内可达性、剂量和时间信息。Agent应把这些桥接条件写成待核验边。

“代谢物作为桥梁”不是一条可以默认成立的箭头，而是一组需要测量与推理共同支持的关系。

## 23.4 数据处理应保留选择过程

缺失值可能来自低于检测能力、峰识别失败或真正的低信号，不应统一解释为零。插补、标准化与批次处理应记录方法，并检查对结果的影响。对于预测任务，这些变换必须在训练数据内拟合，避免利用测试集信息。[R17]

异常样本与质量控制样本应分别标识。删除异常点需要透明规则，不能因为它们破坏预期关联就移除。处理前后应保留样本与特征映射，以便报告哪些数据被改变。

Agent可以自动生成审计报告，但不能根据一个通用模板决定所有代谢组数据的过滤阈值。阈值依赖平台、样本、研究目标与测量质量。

## 23.5 从代谢物到宿主靶点

目标映射可能涉及受体、转运体、酶或其他过程。数据库关系应区分直接结合、功能影响和计算预测。对于同名但结构不同的实体，不能混合靶点记录。

宿主单细胞中观察到某受体转录本，可以支持潜在响应能力，但不能单独证明蛋白存在、配体达到有效暴露或信号被激活。表达、蛋白、活性和细胞状态属于不同层级。

一个有用输出是逐边证据表：M身份是否可靠；M暴露是否被测量；靶点关系是什么类型；目标细胞是否具有相关响应条件；是否存在扰动验证。表中空白比模型补齐的机制更有研究价值。

## 23.6 多个代谢物与多重检验

大量代谢特征与多种细胞状态配对，会产生很大的检验空间。必须明确检验族、筛选策略和校正范围。先用全数据筛选最显著特征，再在同一数据中报告未经选择修正的关联，会夸大证据。

Benjamini–Hochberg方法提供了控制错误发现率的经典思路，但其使用仍有前提，校正也不能修复错误模型或混杂。[R16] 报告应同时给出效应大小、方向和不确定性，而不是只有阈值后的星号。

对探索性候选，下一步可以是独立样本或更直接的测量验证。统计显著不是化学身份确认，也不是机制确认。

## 23.7 用不一致结果修订机制

假设微生物功能增加，但对应代谢物没有增加，可能有多种解释：其他来源与消耗、测量区室不同、功能未表达，或最初假设不成立。Agent应列出可以区分这些解释的资料，而不是立即挑一个最顺畅的故事。

如果宿主响应与代谢物方向相反，也不应自动称为代偿。代偿是一种机制解释，需要相应证据。描述不一致、提出竞争解释、定义下一步检验，是更稳健的顺序。

## 23.8 练习与参考思路

**练习一：**表格中代谢物名称明确，但注释状态为putative，报告如何写？参考思路：保留候选身份和注释等级，对精确结构或靶点推断加限制，必要时优先验证身份。

**练习二：**M在血浆中升高，能否认定来源于某菌？参考思路：不能，仅凭共同变化无法排除宿主、饮食及其他微生物来源。

**本章要点：**代谢身份、数量、来源与区室必须分开；跨尺度桥接不能用一个名称替代实际证据。
