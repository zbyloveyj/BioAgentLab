# 第20章 Literature Agent：从查询到研究级证据表

## 20.1 文献任务从问题定义开始

“检索微生物与免疫”范围太宽，容易返回大量主题相关但无法回答具体问题的材料。先定义研究对象、暴露、响应、研究设计和时间范围，再生成检索词。对于探索性问题，可以分层放宽，而不是一开始把所有概念都堆入同一条查询。

例如先查询 A 与 M 的关系，再查询 M 与 C 的关系，最后搜索同时覆盖二者的研究。每条查询服务于不同 claim，结果不应全部混入一个无来源区分的摘要。

检索策略应保存原始问题、查询表达式、数据库、访问时间和返回数量。后续无法找到某篇文章时，研究者才能检查是词语选择、时间范围还是数据库覆盖造成的。

## 20.2 PubMed 接口的基本流程

NCBI E-utilities提供结构化检索和记录获取接口。ESearch可返回匹配标识，EFetch可获取相应记录，ESummary提供摘要性元数据。[R10] 配套教学适配器采用只读请求，并把网络功能与离线测试分开。

使用接口时应遵守官方速率与标识要求。当前官方文档说明无API key通常限制为每秒3次请求，有key默认可提高到每秒10次；共享IP或多进程仍需整体控制，不应把每个进程都设到上限。[R10]

```python
from urllib.parse import urlencode

params = {
    "db": "pubmed",
    "term": "microbiome AND metabolomics",
    "retmode": "json",
    "retmax": 5,
    "tool": "BioAgentLab",
}
url = (
    "https://eutils.ncbi.nlm.nih.gov/entrez/eutils/"
    "esearch.fcgi?" + urlencode(params)
)
```

这只是请求构造示例。完整实现还需要超时、返回大小限制、错误检查和查询记录。密钥只能从环境变量或安全配置读取，不写入公共日志。

## 20.3 元数据、摘要和全文分别处理

标题与摘要适合初筛，但很多关键方法信息只在全文或补充资料中。Literature Agent不应因为摘要提到某个机制，就自行补全剂量、样本量或统计控制。

元数据表可以记录标题、年份、标识、文献类型与获取状态；摘要表记录可用文本；全文证据表记录具体位置与提取的claim。无法获得全文时，应明确标记，而不是生成看似完整的方法摘要。

PubMed记录可能包含受版权保护的摘要。公开仓库不应无差别重新分发大量全文或摘要；保留查询脚本、合法元数据和必要的引用，遵循来源使用条件。[R10]

## 20.4 筛选规则应预先明确

文献筛选可以分为主题相关性、设计适用性和证据直接性。主题相关不意味着直接支持。例如综述讨论微生物代谢与免疫，但当前claim可能要求同一人群的特定代谢物测量。

可以让模型根据规则提出纳入或排除建议，但保存理由和可核验位置。对于重要综述或系统性证据工作，人工审核与一致性检查仍然必要。不要把自动筛选结果直接称为完整系统综述，除非流程确实满足相应研究要求。

排除理由应具体，如物种不符、缺少目标测量、非原始研究或重复队列。简单标记“低质量”难以复核，也可能把不符合假设的结果错误排除。

## 20.5 研究证据表比逐篇摘要更重要

逐篇摘要适合阅读，但横向比较需要共同字段：研究对象、样本来源、测量方式、效应方向、调整变量、时间关系和限制。只有放在同一结构中，才容易发现所谓冲突其实来自不同情境。

对于同一研究的多个版本，应记录版本关系。预印本与正式发表版本不计作独立研究；撤稿或更正信息需要在实际使用前核查。出版年份也不一定等于研究发生时间，不能仅靠年份推断因果先后。

一个高质量输出不应只列“支持机制的文章”，还应列反对、阴性和无法判断的材料，并说明检索未覆盖的范围。

## 20.6 处理检索失败

空结果、服务错误和解析失败必须区分。空结果表示该查询没有返回记录；服务错误表示没有获得可靠响应；解析失败表示返回格式与预期不一致。三者应触发不同动作。

如果接口暂时失败，可以有限重试并记录错误。若查询过窄，可以有理由地放宽。若实体名称不确定，应先做映射。不能通过不断改变问题直到出现支持结果，再声称检索证实了原假设。

离线测试应使用小型本地响应样例，验证解析与错误处理。它证明适配器对样例工作，不代表当前网络端到端调用已经测试通过。配套项目会在测试报告中明确这一范围。

## 20.7 最终报告如何写

先回答当前证据支持什么，再说明不支持什么，然后列下一步最有信息价值的任务。每条关键陈述绑定来源；计算或筛选数字来自程序汇总，不由模型自由生成。

可以使用这样的句式：“在本次检索纳入的研究中，A与M的关联在指定情境下有支持，但M到C的体内暴露与作用证据仍不完整，因此整条链保留为待验证假设。”它比一段确定性的机制叙事更适合指导下一步研究。

## 20.8 练习与参考思路

**练习一：**摘要没有样本量，模型应该怎样填写证据表？参考思路：保留缺失，标记需要全文核对；不能根据类似研究估算后当成事实。

**练习二：**相同查询今天与一个月后返回数量不同，是否程序错误？参考思路：可能是数据库更新，应比较查询、时间、索引状态与记录；保存访问日期和结果快照才能复核。

**本章要点：**文献Agent应产生可比较、可定位的证据表；没有获得材料时必须保留缺失。
