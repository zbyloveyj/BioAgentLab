# 第14章 Reflection：让批评变成可执行的检查

## 14.1 “请再认真想一次”为什么不够

一个模型生成了假设，再由同一个模型评价，可能纠正遗漏，也可能重复最初的偏差。反思的价值取决于是否引入明确标准、外部结果或新的证据，而不只是增加一轮语言生成。Reflexion 展示了使用反馈和记忆改进后续行为的研究路径，但反馈本身仍需要评估。[R04]

本书把反思定义为对具体对象的定向检查。对象可以是一条 claim、一个统计方案或一个报告段落；检查结果应该指出问题位置、问题类型、严重程度和建议行动。只写“需要更多验证”很难帮助下一步决策。

例如：“该陈述把粪便浓度解释为循环暴露，现有证据没有相应样本测量；建议将表述降级为局部关联，并检索暴露证据。”这条批评比“机制尚不清楚”更有用。

## 14.2 建立批评分类

可以把常见问题分为实体错误、证据错误、方法错误、逻辑错误和范围错误。实体错误包括别名混淆；证据错误包括引用不存在或方向不符；方法错误包括分析单位不正确；逻辑错误包括因果倒置；范围错误包括从动物结果直接推广到人群。

每种类别应对应不同处理。引用不存在，需要删除或重新检索；方法错误，需要停止相关分析；外推过强，可以修改表述并保留限制。把所有批评都转成扣分，会丢失处理上的差异。

```python
critique = {
    "target_id": "H1:v1",
    "category": "scope_mismatch",
    "severity": "blocking",
    "evidence_ids": ["E002"],
    "problem": "Cell-culture result used as human causal evidence",
    "action": "narrow_claim_and_reverify",
}
```

`blocking` 表示在问题解决前，相关结论不能进入最终报告。它不是表示整个项目必须停止，而是阻止特定错误传播。

## 14.3 对 claim 的逐项核验

先把待核验陈述拆成最小可判断部分，再逐一比较来源。核验时应保留原文位置，避免只检查另一段摘要。可以依次问：来源是否存在？实体是否一致？方向是否一致？设计是否支持当前动词？结论有没有超出样本和条件？

例如原文说“未观察到组间显著差异”，模型摘要却说“该组呈明显下降”。这是方向与统计表述错误。又如原文报告“表达与表型相关”，摘要写成“表达驱动表型”，这是因果层级提升。两者都需要修改，而不是简单在句末加“可能”。

GeneAgent 的自校验思路提醒我们，把生成文本拆成可查询陈述有助于联系领域数据库。[R07] 但数据库能否回答某种 claim，也要检查；数据库缺少记录不能自动成为反证。

## 14.4 统计审查不能被语言评审替代

模型可以发现明显不合理的分析方案，但不能仅凭文字确认统计计算正确。应运行确定性测试，核对样本数、分组、缺失值处理、协变量和多重检验范围。真实模型的适用性还需要领域与统计专业判断。

假设报告写“共有 20 名供体、40,000 个细胞，因此 n=40,000”。反思模块应把分析单位问题标记为阻断项。即使每一步软件都成功运行，也不能把细胞数量当作独立供体数量。

又如微生物组成数据的某个分量升高，可能导致其他分量的相对比例下降。反思应追问测量尺度与归一化，而不是只让模型解释“为什么这些菌同时减少”。这体现了对数据生成过程的审查。

## 14.5 对照审稿人与对抗审稿人

可以设置一位支持性评审，要求找出假设最合理的解释；再设置一位对抗性评审，寻找最强替代解释。两者并非扮演情绪化的赞成和反对，而是分别检查论证的正面与薄弱部分。

角色分配不保证独立性。多个角色如果使用相同模型和材料，可能共享盲点。因此，真正重要的异质性来自不同证据、不同检查规则以及独立专家复核。不能把“有五个 Agent 同意”当作科学共识。

为了减少相互影响，可以先让评审独立给出结构化意见，再进行综合。不要一开始就给后一个评审看前一个的结论，否则很难区分独立判断与跟随。

## 14.6 批评也需要核验

反思模块可能提出不存在的问题。例如它可能声称某研究没有控制年龄，实际补充表中已经控制。批评不能因为语气严厉就被自动接受。对有来源的批评，应回到材料核对；对无来源的推测，应标记为待查事项。

批评记录可以有 `open`、`confirmed`、`resolved`、`not_supported` 四种状态。解决后仍保留历史，便于了解假设为什么发生变化。不要把已被否定的批评长期留在扣分列表中。

这一点也解释了为什么“批评越多，质量越低”的简单排名不可靠。一个受到认真审查的好假设可能产生更多已解决批评，而一个空泛假设反而难以被具体挑错。

## 14.7 反思预算与停止

反思应有明确目标与次数上限。每轮至少解决一个具体问题，或识别一个新的关键空缺。如果多轮只是在改写同样的泛泛意见，应停止并交给人工审查，而不是继续消耗资源。

报告应记录未解决问题，而不是通过语言润色把它们隐藏。反思的成功不是最终文本没有任何限制，而是限制准确、可定位，并且不会在后续摘要中消失。

## 14.8 练习与参考思路

**练习一：**模型指出“需要更大样本量”，如何让批评可执行？参考思路：说明需要提高哪一个估计的精度、当前不确定性在哪里，以及独立样本与增加细胞数量的区别；不能直接凭模型给出正式功效计算。

**练习二：**反思发现原假设的关键引用不相关，应如何处理？参考思路：撤销该引用对 claim 的支持，重新检索或将 claim 标为证据不足；不要换一个更模糊的句子继续保留原支持状态。

**本章要点：**反思应产生定位明确的检查与行动；批评自身也需要证据，角色数量不能替代独立性。
