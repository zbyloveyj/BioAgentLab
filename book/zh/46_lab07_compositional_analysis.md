# 实训七 组成数据的数值性质与解释边界

## 目标与一个三类群例子

本实训通过可手算的小向量理解组成效应。不要先寻找显著P值，先确认相对丰度究竟表达什么。设初始绝对数量为10、10、10，第二次为20、10、10。

```python
before = [10, 10, 10]
after = [20, 10, 10]
relative_before = [x / sum(before) for x in before]
relative_after = [x / sum(after) for x in after]
print(relative_before)
print(relative_after)
```

第二、第三类群的绝对数量不变，但相对比例从三分之一降到四分之一。写一段解释，说明为什么不能仅凭相对下降宣称它们受到抑制。

## CLR与尺度不变性

使用项目函数计算CLR，并检查分量和。再将全部数值乘以10，结果应保持不变。这是严格正向量的相对尺度性质。

```python
from bioagent.biology import clr
import math

x = [1, 2, 4]
a = clr(x)
b = clr([10 * v for v in x])
assert abs(sum(a)) < 1e-12
assert all(abs(u-v) < 1e-12 for u,v in zip(a,b))
print(a)
```

手算时，几何均值为2，因此结果为负log2、0、正log2。这个已知结果很适合作为单元测试；若程序不符合，先检查实现而不是寻找生物解释。

## 零值需要显式决定

把输入改成0、2、4。默认函数应拒绝，因为不能直接取log。显式提供伪计数后可以计算，但必须记录这个选择。

```python
try:
    clr([0, 2, 4])
except ValueError:
    print("Zero handling required")
for p in [0.01, 0.1, 1.0]:
    print(p, clr([0, 2, 4], pseudocount=p))
```

比较不同伪计数下的差异。固定加数相对于输入尺度的大小会改变结果，因此不能把它隐藏在工具内部。对真实组成数据，应结合零值来源和分析方法选择适当处理。

## 全零样本与低信号样本

全零向量没有可解释的组成，不能通过加伪计数变成“所有菌均匀存在”。项目函数因此拒绝全零样本。这个拒绝避免把缺失或处理失败转成虚构生态状态。

低信号样本也需要质量检查。归一化可以改变尺度，却不能创造测量信息。Agent不应因为变换后矩阵数值正常，就宣布样本质量没有问题。

## BH校正的手工核对

给四个P值0.01、0.04、0.03、0.002，先排序，再按检验数与秩调整，并从后向前取累积最小值。使用函数核对结果。

```python
from bioagent.biology import bh_adjust
p = [0.01, 0.04, 0.03, 0.002]
q = bh_adjust(p)
print(q)
assert all(0 <= value <= 1 for value in q)
```

预期原顺序对应0.02、0.04、0.04、0.008。注意，这些数值是教学输入，不能被解释成微生物差异分析结果。BH也不能修复错误的检验模型。

## 从数值到报告

写两版报告：第一版故意把相对下降说成绝对减少，第二版修正测量尺度。再指出第二版还缺少哪些信息，例如绝对定量、协变量、批次和独立验证。

这样的练习训练的是解释边界。一个Agent可以很快计算CLR，但如果后续仍用绝对数量语言解释，数值变换并没有解决科学问题。
