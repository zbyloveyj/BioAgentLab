# 第24章 Single-cell Agent：先守住数据层，再解释细胞

## 24.1 一个h5ad文件仍然需要审计

AnnData常用于组织单细胞矩阵与元数据，但文件格式本身不能告诉你矩阵是否为原始计数、对数表达或整合表征。Agent读取文件后应检查层、观测信息、变量信息和处理记录，而不是默认 `X` 就是计数。[R12]

样本、供体、批次、细胞类型和实验条件应具有明确字段。缺少供体标识时，后续组间差异推断可能无法正确处理生物学重复。细胞数再多，也不能补足不知道独立单位的问题。

本章介绍如何组织可靠工作流；配套轻量代码只演示数据契约和聚合，不包含完整单细胞生产分析。

## 24.2 保存原始计数与处理历史

归一化和对数转换会改变矩阵含义。需要原始计数的方法不能直接接受处理后的矩阵。建议在明确确认输入为原始计数后，保存到独立层，并记录后续每一步变换。[R12]

```python
# 适用于已确认 adata.X 为原始计数的场景。
# 本段依赖可选的 scanpy，不在标准库演示中执行。
import scanpy as sc

adata.layers["counts"] = adata.X.copy()
sc.pp.normalize_total(adata, target_sum=1e4)
sc.pp.log1p(adata)
adata.uns["processing_note"] = {
    "counts_layer": "counts",
    "normalization": "normalize_total_then_log1p",
}
```

这里的目标总量是示例参数，不是所有数据的通用最优设置。更重要的是知道每个层代表什么，并让下游函数检查自己需要的输入层。

## 24.3 质控没有万能阈值

基因数、总计数、线粒体比例和其他指标可以帮助发现异常，但阈值需要结合组织、技术、样本和研究目标。某些真实细胞状态也可能具有特殊指标，机械过滤会改变生物组成。

Agent可以展示分布、按样本比较并提出检查建议，但不应在没有上下文时自动套用固定阈值。过滤前后要记录每个样本保留的细胞数，以及条件组是否受到不对称影响。

双细胞、环境RNA、低质量细胞和样本混淆需要不同方法检查。把它们全部归结为“批次效应”会使后续处理失去针对性。

## 24.4 聚类与注释是分析结果，不是天然标签

降维和聚类依赖特征选择、邻居图、分辨率与随机性。不同参数可能改变边界。Agent应保存这些选择，并通过标记基因、参考映射和样本分布检查结果，而不是仅凭UMAP上分开的形状命名细胞。

细胞注释可以结合多个证据来源，但必须容纳未知与混合状态。一个自动注释工具给出标签，并不意味着标签绝对正确。对关键细胞群，应检查正向与排除性标记、供体覆盖及潜在技术因素。

模型生成的细胞名称应绑定依据，不能通过检索几个相关基因就创造一个看似新颖的亚型。亚型解释需要稳定性与独立验证。

## 24.5 整合用于什么，差异检验用于什么

批次整合可以帮助构建可比较表征，但不意味着所有后续统计都应使用整合后的数值。差异表达应选择与统计模型和设计匹配的数据层，避免把用于可视化的嵌入当作表达量。

若批次与疾病完全混杂，任何算法都难以仅凭数据区分技术与生物效应。Agent应报告设计限制，而不是宣称通过一个整合函数已经解决。

可以比较整合前后已知生物结构与批次结构，但评价不能只追求“所有批次混得越均匀越好”。过度校正可能抹去真实差异。

## 24.6 细胞比例与细胞状态分别分析

疾病组某种细胞更多，与同一细胞类型内部表达状态改变，是两个不同问题。前者涉及组成与样本级比例，后者涉及供体内聚合或层级模型。把全部细胞混合做差异，可能同时混入比例与状态变化。

因此，报告应先说明研究的是丰度变化、表达变化还是两者。细胞比例也受组织取样、捕获和处理影响，不是直接的体内绝对细胞计数。

对跨组学关联，最好在供体或样本层面形成可解释的细胞状态摘要，再与其他组学对齐，而不是将同一供体的微生物值复制到每个细胞后当作独立配对。

## 24.7 与代谢物机制连接时保持克制

观察到细胞C表达候选靶点，可以帮助定位潜在响应细胞；观察到相关通路状态，则增加功能线索。但配体暴露、靶点蛋白和实际信号活动仍可能缺失。

Agent可以把这些信息组织成“响应能力—状态变化—暴露证据”三栏。这样既能提出有价值的跨尺度假设，又不会把转录数据直接写成代谢物作用已经发生。

## 24.8 练习与参考思路

**练习一：**不知道 `adata.X` 是否经过log转换，能否直接做计数模型？参考思路：不能，先检查数据说明与保存层；无法确认时应停止相关分析。

**练习二：**某聚类只来自一位供体，应优先考虑什么？参考思路：检查供体特异生物状态与技术因素，不能直接命名为疾病特异细胞类型。

**本章要点：**数据层、供体信息和处理历史优先于漂亮可视化；细胞标签和跨尺度机制都需要证据。
