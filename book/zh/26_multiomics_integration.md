# 第26章 多组学整合：先对齐人，再连接机制

## 26.1 多组学不是把矩阵并排放置

微生物、代谢组和单细胞矩阵的样本单位可能不同：一次粪便采样、一管血浆、一位供体的细胞，甚至来自不同队列。整合之前，必须明确哪些观测可以对应，时间是否接近，以及缺失是否具有系统性。

两个矩阵各有一百行，不意味着它们可以逐行相关。按排序后的行号配对，是非常隐蔽也非常严重的错误。Agent必须使用稳定标识和明确连接规则，并保存连接前后的样本流失。

如果数据来自不同人群，仍可做跨研究证据整合或知识层连接，但不能声称完成了样本级关联分析。

## 26.2 构建配对清单

配对清单应包含供体、时间、样本类型、组学文件、质量状态和允许的时间窗口。重复标识、一个样本对应多个文件或不一致的分组，都应在分析前解决。

```python

def align_by_id(left, right):
    def index(rows):
        result = {}
        for row in rows:
            key = row["sample_id"]
            if not key or key in result:
                raise ValueError("Missing or duplicate sample ID")
            result[key] = row
        return result
    a, b = index(left), index(right)
    common = sorted(set(a) & set(b))
    return {
        "pairs": [(a[k], b[k]) for k in common],
        "left_only": sorted(set(a) - set(b)),
        "right_only": sorted(set(b) - set(a)),
    }
```

这里仅按样本ID连接。真实纵向项目还需额外检查时间与取样条件，不能把同一供体不同时间点自动视为同一生物状态。

## 26.3 三种整合层次

**早期整合**在适当处理后组合特征；**中间整合**学习共享或特异表征；**后期整合**组合不同模态的结果或证据。选择取决于样本配对、维度、缺失和研究目标，而不是哪个名词更先进。

微生物具有组成约束，代谢信号有鉴定与单位问题，单细胞需要供体层级汇总。它们进入共同模型之前应分别完成领域适当的处理。不能用同一标准化函数抹平所有差异，然后把模型结果视为统一尺度的生物机制。

共享表征可以捕获共变结构，但共享不等于因果中介，特异不等于疾病特异机制。模型名称与生物解释之间仍需证据。

## 26.4 一个最小统计问题

先选择一个经过定义的微生物功能、一个可靠代谢物和一个供体层级宿主状态，检查三者在可配对样本中的关系。这个小问题可以暴露数据对齐、单位、混杂与缺失处理中的错误。

相关系数可以作为探索性摘要，但需要说明协变量、异常值、批次和多重比较。跨模态高维模型则更需要训练与验证分离，所有特征选择和变换在训练环节完成。[R17]

若样本量相对于维度很小，应特别关注过拟合与不稳定。模型能够拟合训练数据，不等于它找到具有可重复性的跨尺度关系。

## 26.5 共享与特异的验证

一个声称跨疾病共享的模式，应在多个疾病或队列中接受预定验证；一个声称疾病特异的模式，需要直接比较差异，而不是因为在A显著、B不显著就宣布特异。

类似地，两个模态都出现相关通路，并不说明它们之间存在样本级耦合。需要检查效应方向、个体对应以及共同混杂。跨尺度一致性是有价值线索，但不是因果链的自动闭合。

Agent可以把每种主张对应的验证要求列成任务表：共享需要复现，特异需要对比，预测需要外部验证，机制需要更直接证据。

## 26.6 缺失模态不是简单补零

没有测量的代谢物与测量值为零不同，没有某种细胞与没有捕获到足够细胞也不同。缺失可能与疾病、批次或样本质量相关，因而不能默认随机。

插补或缺失模态模型需要明确假设，并在验证中模拟合理缺失情形。报告应说明哪些结果依赖插补，哪些来自实际观测。不能把推断值重新标记为测量值进入证据台账。

对教学工作流，最稳妥的做法是先严格限制为完整且可配对的小样本演示，同时输出被排除对象和原因；真实项目再根据设计选择更合适方法。

## 26.7 从模型输出到机制报告

模型可能给出一组权重、潜变量或网络。解释之前要检查稳定性、方向一致性和外部复现，再把候选映射回功能证据。高权重不一定意味着重要因果作用，相关特征之间也可能相互替代。

报告可以分为数据关系、知识支持和机制假设三层。第一层来自计算，第二层来自文献或数据库，第三层是整合推理。明确分层可以避免将多个弱线索合成一段过强结论。

## 26.8 练习与参考思路

**练习一：**微生物和单细胞来自不同队列，能否做个体相关？参考思路：不能。可以做证据或群体结果层面的整合，但必须改变问题与表述。

**练习二：**A疾病显著、B疾病不显著，能否称A特异？参考思路：需要直接检验效应差异并考虑功效、样本与测量差异，不能用两个P值的不同替代差异检验。

**本章要点：**样本、时间与尺度对齐先于整合；共享表征、统计耦合和机制因果需要不同验证。
