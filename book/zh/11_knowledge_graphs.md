# 第11章 知识图谱：把关系保存下来，也把边界保存下来

## 11.1 为什么表格和段落还不够

当研究涉及微生物、基因、反应、代谢物、受体、细胞和表型时，许多问题本质上是在问“哪些对象通过哪些关系连接”。知识图谱把对象表示为节点，把关系表示为边，方便查询跨层连接与证据空缺。

但图谱不是事实的自动担保。一张图中出现 A→M→C，只说明系统保存了两条关系，不说明它们已经组成因果链。尤其当两条边来自不同物种、组织或时间条件时，路径可能在生物学上不能直接连接。

因此，本书强调带情境的图谱。边不仅包含主体、关系和客体，还应包含来源、研究类型、方向、测量层级与适用条件。图谱越容易画得漂亮，越应该认真检查这些不显眼的字段。

## 11.2 实体标准化先于连边

一个实体可能有多个名字，一个名字也可能对应多个实体。基因符号可能变化，代谢物可能有异构体，微生物名称可能因分类修订而改变。直接按字符串拼接，会产生错误合并或重复节点。

建议每个节点包含命名空间、稳定标识、显示名称、别名、物种或结构信息，以及映射来源。显示名称服务于阅读，稳定标识服务于计算。无法唯一映射时，应保留候选集合与不确定状态，而不是随意选择最熟悉的名称。

在微生物研究中，还应区分物种、菌株、MAG 和功能基因簇。把物种节点连接到某代谢反应，并不表示每个菌株都具有相同能力。节点粒度决定后续推断能走多远。

## 11.3 边的类型决定它能说明什么

“相关”“编码”“催化”“结合”“表达于”和“改善”不是同一种关系。把所有边统一写成 `related_to` 虽然方便导入，却会丢失重要科学语义。图查询返回一条路径时，必须考虑路径中每种关系的含义。

例如，基因 G `encodes` 酶 E，E `catalyzes` 反应 R，R `produces` 代谢物 M。这是一条功能能力链。若再加入物种 A `contains` G，它支持某种潜在能力，但仍不等于在当前环境中实际产生了足够的 M。基因存在、转录、酶活与代谢通量属于不同层级。

```python
edge = {
    "subject": "microbe:A",
    "relation": "associated_with",
    "object": "metabolite:M",
    "direction": "positive",
    "context": {
        "sample_type": "stool",
        "design": "observational",
    },
    "evidence_ids": ["E001"],
    "status": "requires_review",
}
```

这里故意没有使用 `causes`。关系名称应反映证据允许的陈述，而不是研究者最希望看到的机制。

## 11.4 一条路径的可靠性怎样判断

常见的诱惑是把每条边赋一个分数，再将路径上的分数相乘。只有在分数具有明确概率含义、依赖关系得到处理等条件下，这种运算才可能具有相应解释。大多数教学或启发式评分不满足这些条件。

更稳妥的做法是先输出逐边证据表，再指出最弱环节。路径中的任何关键边缺失，都应让整条机制链保持待验证状态。多个强相关边不能自动补足一条不存在的暴露或干预边。

可以把路径审计拆成三问：对象是否能正确对齐？关系是否在当前情境中适用？连接这些关系是否需要额外假设？这三问比一个未经校准的“路径置信度 0.87”更有解释力。

## 11.5 图谱查询与语言模型的分工

结构化图查询适合稳定规则，例如找出与代谢物 M 相连的受体、再查受体在哪些细胞类型中有表达记录。语言模型可以帮助把研究问题转成候选查询，但查询应经过模式和权限检查。

不要让模型任意生成可写入或删除数据库的查询。对只读研究任务，可以限制为预定义查询模板，或在执行前解析并验证。查询失败时，应返回具体错误，而不是让模型编造一张“预期结果表”。

当图谱缺少某种关系时，系统应说明这是数据库覆盖空缺，不一定是生物学关系不存在。图谱的负边需要明确的负证据定义，不能简单把未连接节点都当成阴性样本。

## 11.6 开放世界与封闭世界

在封闭世界假设下，数据库中没有某条事实可以被视为假。许多生物医学知识库更接近开放世界：缺少记录只表示未知。对科研 Agent，这个区别尤其重要。

例如数据库没有记录某菌株产生 M，可能因为该菌株尚未被研究，而不是它不能产生 M。系统可以据此提出待验证的能力问题，但不能直接把未注释写成“无此功能”。同样，一条数据库注释也可能是计算预测，需要与实验验证区分。

这也是知识图谱预测任务容易发生评价偏差的地方。把所有未记录边作为负例，会混入未来可能被证实的关系。科研系统应明确负例的来源和时间边界。

## 11.7 用小图练习完整审计

先用十几个节点构建一个可人工核对的小图。每条边至少绑定一个来源记录；故意加入一个别名冲突、一个物种不匹配和一条仅由模型提出的假设边。然后编写查询，检查系统是否会把假设边当成已知事实。

这个练习比一开始导入几百万条关系更有价值。规模扩大之前，应先确保实体、关系和证据语义正确。错误的大图往往比正确的小图更难修复。

## 11.8 练习与参考思路

**练习一：**A 与 M 在粪便中相关，M 在细胞培养中影响 C，可以输出什么？参考思路：可以形成跨层候选机制，但仍缺少体内暴露、组织可达性和条件匹配等证据，不能直接认定 A 在人群中通过 M 改变 C。

**练习二：**图谱中没有边，能否作为反证？参考思路：通常不能。必须区分数据库未覆盖与经过设计的阴性证据。

**本章要点：**图谱保存关系，也必须保存关系的来源与适用条件；路径不是因果证明。
