# BioAgentLab Benchmark

The benchmark will evaluate whether a biology agent is scientifically useful rather than merely fluent.

Planned dimensions:

- evidence-grounding accuracy,
- provenance correctness,
- tool-selection accuracy,
- tool-execution success,
- unsupported-claim rate,
- hypothesis quality,
- redundancy,
- reproducibility,
- recovery from tool failure,
- cost and latency.
