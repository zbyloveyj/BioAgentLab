# 01 环境安装（Windows 与 Jupyter）

**所需软件**：Git、Python 3.10+（推荐 3.11/3.12）、VS Code 或 Jupyter Lab。建议先在 PowerShell 中完成安装，再打开 Notebook。

```powershell
git --version
py --version
git clone https://github.com/zbyloveyj/BioAgentLab.git
cd BioAgentLab/courses/openai-agents-sdk-zh
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -U pip
python -m pip install -e ".[notebook,dev]"
Copy-Item .env.example .env
python lessons/00_environment_check.py
pytest -q
```

PowerShell 若无法激活虚拟环境，可执行 `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass`（只对当前窗口有效），或完全不激活，改用 `.\.venv\Scripts\python.exe`。

**不要把 API Key 写进脚本。** 用文本编辑器打开 `.env`，在 `OPENAI_API_KEY=` 后面填写你本人创建的密钥；`NCBI_EMAIL=` 后面填写真实邮件地址。保存后再打开新终端运行课程。

打开 Jupyter：`python -m jupyter lab`。在文件浏览器中打开 `notebooks/00_开始之前.ipynb`，依次运行代码单元。内核应选当前 `.venv` 所在 Python。Notebook 与脚本不一样：可以直接使用 `await Runner.run(...)`，而独立脚本可用 `Runner.run_sync(...)`。

**安装失败**：先确认网络能访问 pip 镜像，使用 `python -m pip --version` 检查 pip 绑定的 Python，检查终端所在目录是否有 `pyproject.toml`。
