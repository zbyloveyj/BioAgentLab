# 02 从第一行到执行循环

## 从 `Agent` 开始

```python
from agents import Agent, Runner
agent = Agent(name="科研助理", instructions="用中文回答问题并标注不确定性。", model="gpt-5-mini")
result = Runner.run_sync(agent, "什么是shotgun宏基因组测序？")
print(result.final_output)
```

第一行从 SDK 导入对象。第二行创建一个 Agent，它类似配置文件，不会因为创建就立刻收费。第三行才触发模型请求，获得 `RunResult`。最后一行只打印最终输出。

## 加入工具

```python
from agents import function_tool

@function_tool
def count_samples(group_a: int, group_b: int) -> int:
    """返回两个队列的样本总数。"""
    return group_a + group_b
```

工具是普通 Python 函数加一层 SDK 封装。类型注解 `int` 帮助 SDK 生成参数 Schema；文档字符串是让模型选择工具时理解用途的重要信息。把 `tools=[count_samples]` 交给 Agent，模型便可以根据任务请求调用它。

**工具实际执行、函数返回值、最终回答**三者是不同的：模型可能选择不调用工具，工具可能出错，模型也可能误读工具的结果，所以科研任务需要日志、结构化输出、人工校验。

## 注意异步

- `Runner.run_sync(...)` 适合命令行脚本。
- `await Runner.run(...)` 适合 Jupyter 交互式单元。
- `Runner.run_streamed(...)` 返回一个事件流，需要异步遍历事件。

练习：将指令改成「每次说明证据来自模型知识还是工具结果」，观察回答是否改变。
