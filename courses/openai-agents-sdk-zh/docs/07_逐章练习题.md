# 07 十二课学习检查与扩展练习

## 00 环境

思考：为什么一台电脑上可能有多个 Python？为什么建议创建虚拟环境？实践：运行 `python lessons/00_environment_check.py`，记录 Python 版本以及缺少的包。

## 01 First Agent

思考：`Agent(...)` 什么时候发起请求？`Runner.run_sync(...)` 什么时候发起请求？实践：修改 `instructions`，要求用 100 字解释宏基因组，观察回答。

## 02 Function tools

思考：你在什么情况下会选用 `lookup_microbe`？实践：给 `agent_course/data.py` 增加一个教学条目，并修改提问测试是否命中。

## 03 Structured output

思考：结构化数据能保证真实科学结论吗？实践：在 Pydantic 模型增加 `validation_strategy` 字段，观察 JSON 内容。

## 04 SQLiteSession

思考：会话数据库中会存储哪些上下文？是否应该保存真实患者资料？实践：修改 session ID，观察第二轮能否沿用原来的记忆。

## 05 PubMed

思考：PMID、PMCID、DOI 有什么区别？实践：更换检索式并核对 2 篇结果的 PubMed 链接，检查是否与代码返回的题目一致。

## 06 RAG

思考：文档召回和答案生成有什么不同？实践：删掉某个本地教学条目后观察 Agent 如何处理证据不足的问题。

## 07 Handoffs

思考：为什么最终回答由 `last_agent` 给出？实践：改成生物统计与 Python 两个专家，比较路由。

## 08 As tools

思考：主控 Agent 为什么仍要最终总结？实践：让方法顾问输出三项潜在混杂因素，再让表达顾问压缩成一段话。

## 09 Streaming

思考：流式输出是否意味着模型运行更快？实践：逐字观察输出；区分增量事件与最终答案。

## 10 Guardrails

思考：为什么关键词检测不能作为完整的科研安全机制？实践：写出本规则可能误报的两种情况，再设计更可靠的策略。

## 11 Research pipeline

思考：为什么把原始 PubMed XML / 摘要与 AI 生成摘要分开保存？实践：检查 CSV 的 PMID 列，任选一篇到 PubMed 核对标题。

## 12 Offline

思考：为什么课程里的本地教学笔记没有 PMID？实践：运行后打开 CSV，核查没有伪造真实文献编号。

## 毕业项目建议

在不输入敏感数据的前提下，做一个“疾病 → PubMed 证据 → 菌种关联 → 结构化表格”的小工具：必须有原始来源链接、去重、失败重试、人工核查记录和至少一个离线测试。
