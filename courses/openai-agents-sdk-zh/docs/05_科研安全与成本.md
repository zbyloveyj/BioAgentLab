# 05 科研安全、费用与证据

## 模型费用

Agents SDK 开源 Python 库的安装与 API 账单是两回事。实际模型请求会产生模型用量；工具调用返回文本、长历史、多 Agent 循环都会增加输入/输出 token。请登录 OpenAI API 账单页面设置预算与用量告警。

## NCBI 规范

必须使用真实 NCBI_EMAIL；本教程程序默认每次检索使用两次 E-utilities 请求，未提供 API key 时在请求间暂停至少 0.4 秒。批量采集需要遵守 NCBI 文档的总速率与访问政策。勿绕过付费论文访问控制。

## 科学质量

- 按 PMID 保存题目、日期、原始摘要和检索时间。
- 限制自动抽取为“观察到的、摘要直接支持的事实”；不要自动构造不存在的实验结论。
- 区分模型的**总结**与文献的**原始摘要**；对于方法细节，必要时阅读原文正文。
- 研究中的真实病人信息、临床原始记录和未公开数据不要直接传到公开模型接口；需先获得数据治理/伦理审批。

## 秘钥与日志

`.env` 在 `.gitignore` 里，避免公开。课程把 `OPENAI_AGENTS_DISABLE_TRACING` 默认为 1；追踪在 SDK 中默认可启用，但可能包含输入和工具输出。生产环境需要脱敏、访问管理和审计。
