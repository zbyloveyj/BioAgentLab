# 06 常见问题与排查

**ModuleNotFoundError: agents**：确认你在课程目录执行了 `python -m pip install -e ".[notebook,dev]"`，Jupyter 内核是否也是该环境。别安装名为 `agents` 的其他无关包；正确 PyPI 包是 `openai-agents`。

**401 / invalid_api_key**：密钥错误、未加载或已失效。检查 `.env` 文件位置；不要打印密钥。创建/更新 Key 后在终端重新运行程序。

**429 / quota**：可能是余额、额度或速率限制问题，需到平台查看；ChatGPT 订阅不代替 API 额度。避免一次性运行全部联网课程。

**model_not_found**：当前账号无权限访问 `.env` 指定的模型，在你账户支持的模型列表里换成可用的。

**No module named jupyterlab / ipykernel**：运行 `python -m pip install -e ".[notebook,dev]"`，并在 Notebook 中选择正确的内核。

**PowerShell 不允许 Activate.ps1**：仅对当前窗口执行 `Set-ExecutionPolicy -Scope Process Bypass`，或使用 `.venv\Scripts\python.exe`，不必修改全局策略。

**NCBI_EMAIL 未配置**：在 `.env` 中设置真实邮箱；不要硬编码他人的邮箱。

**PubMed 返回空**：可能检索词过窄，先尝试 `gut microbiome AND depression`；网络受限、NCBI 暂时不可访问也会影响结果。

**输出目录找不到**：程序执行后生成 `outputs/`，它被 Git 忽略；不要把患者信息导出到此教学仓库后提交。

**VS Code/Notebook 报 async 错误**：Notebook 里用 `await Runner.run(...)`；脚本里使用 `Runner.run_sync(...)` 或 `asyncio.run(...)`。

**工具不调用**：检查是否在 `Agent(tools=[...])` 中注册、指令是否明确、函数文档字符串和参数注解是否清晰。模型是否调用工具不是硬编码的必然事件。
