# 00 核心概念：为什么 Agent 不等于聊天机器人？

## 1. 最短定义

LLM（大语言模型）负责理解和生成；Agent（智能体）是“LLM + 指令 + 工具 + 运行循环”的一种软件组织方式。**大模型做选择，Python 工具执行实际动作，Runner 管理这个过程。**

举例：你问「Akkermansia muciniphila 是什么？」普通模型可以直接解释；但你问「检索 PubMed 上近年的文章，给 PMID、摘要和日期并导出证据表」就需要工具和可复现的数据处理过程。

## 2. 四个核心对象

`Agent(name, instructions, model, tools)`：定义任务角色和边界。\
`Runner.run(...)` / `Runner.run_sync(...)`：真正执行，可能多次调用模型和工具。\
`@tool`：把一个有清楚参数和 docstring 的 Python 函数包装为模型可以调用的工具。\
`result.final_output`：执行完成后的最终答案；不是模型的所有内部工具调用记录。

## 3. SDK 与 API 的区别

SDK 是 Python 库（程序代码），API 是收费/计量的模型服务接口，API Key 是授权凭证。没有 API Key 也可以做本地检索与程序测试，但不能执行本课程的在线模型调用。

## 4. 如何看一次调用

用户问题 → Runner 把指令/可用工具发送给模型 → 模型决定回答或请求调用工具 → Python 执行工具 → 工具结果返回模型 → 模型组织答案 → Runner 返回 RunResult。

这一循环不是「模型可以随意执行 Python」，只有注册过的工具函数才在可执行范围内。

## 5. 三种初学者常混淆的功能

- RAG：先检索外部资料，然后让模型基于检索结果回答。本项目用**本地关键词检索**展示逻辑，不冒充向量语义检索。
- Memory：为连续问答保存前文，`SQLiteSession` 是示例。它并不等于模型永久记住用户。
- Multi-agent：多个角色分工，`handoffs` 允许路由转交，`as_tool` 让总控始终负责最终答案。
