# Biology workflows

The implemented teaching workflow is `bioagent.demo.run_demo`, exposed as `python -m bioagent demo`.

It runs synthetic data audit, registered CLR/pseudobulk tools, local retrieval, evidence aggregation, scripted model roles, transparent pairwise preference ranking, revision/re-verification and report production. It does not make real biological claims.

The book teaches how to extend this to literature, microbiome, metabolomics, single-cell and multi-omics settings. Full production adapters for those pipelines are not yet implemented; see `docs/CAPABILITIES.md`.
